# Bug Tracking — DSA and Software Engineering V.0.1

This file tracks all identified bugs, edge cases, and their corresponding resolutions.

| Bug ID | Date Reported | Description | Severity | Status | Solution / Fix |
|---|---|---|---|---|---|
| BUG-001 | 2026-10-06 | Unicode characters (`→`, `☑`, `☐`) in initial Python Excel extraction script caused `charmap` encode error on Windows cp1252 terminal. | Medium | Resolved | Reconfigured Python stdout to `utf-8` via `sys.stdout.reconfigure(encoding='utf-8')` and parsed cell hyperlinks directly through openpyxl target extraction. |
| BUG-002 | 2026-10-06 | Review days (Day 7, 14, 21, etc.) and Mock day (Day 90) have null problem numbers (`num: null`) which could corrupt numerical sorting and total problem counter. | Medium | Resolved | Structured problem key generator to handle non-numbered items (`day_${day}_${problem}`) and restricted primary problem counter to items with valid `num` values, preventing inflation of the 150 problem target. |
| BUG-003 | 2026-10-13 | Initial "More" dropdown HTML markup in `index.html` lacked CSS stylesheet rules and `toggleMoreDropdown` JavaScript handler, causing the dropdown trigger button to render unstyled and fail to toggle on click. | Medium | Resolved | Added `.nav-more-dropdown` styling suite in `styles.css` and implemented `toggleMoreDropdown()` with outside-click and Escape listeners in `app.js`, synchronizing across all portals. |
| BUG-004 | 2026-10-24 | Truncated event listener in `dsa_roadmap.html` caused `SyntaxError: Unexpected end of input` halting script execution and leaving main content blank. Additionally, `.cba-nav-tabs` had `overflow: hidden` in `shared-nav.css`, clipping the More dropdown menu. | High | Resolved | Removed truncated listener block in `dsa_roadmap.html`, allowing `render()` to execute cleanly. Set `overflow: visible` on `.cba-nav-tabs` and added `:hover` support to `.cba-more-dd`. |
| BUG-005 | 2026-10-24 | `dsa_pattern_guide.html` and `DSA Pattern Guide.html` rendered in light theme by default due to `:root` defaulting to `--bg: #f7f6f2` instead of dark theme, and `shared-nav.js` did not initialize `data-theme` on page load. | Medium | Resolved | Updated `:root` CSS variables in pattern guide pages to dark theme by default, and updated `shared-nav.js` to initialize `document.documentElement.setAttribute('data-theme', theme)` from `localStorage` on load. |
| BUG-006 | 2026-10-24 | More dropdown menu failed to stay open on mouse hover due to 10px hover gap between trigger button and menu; on mobile viewports (<=768px/480px), `.cba-more-menu` extended off-screen due to `left: 0` without responsive bounds; and client browsers served cached `shared-nav.css` from deployment due to missing cache-busting version queries. | High | Resolved | Added invisible hover bridge (`::before` / `::after`) in `shared-nav.css`, added responsive right-anchoring and fixed viewport bounds for mobile, synchronized `aria-expanded` and touchstart listeners in `shared-nav.js`, and added version query parameter `?v=0.5.2` across all 7 portal HTML files to bust CDN/browser cache. |
